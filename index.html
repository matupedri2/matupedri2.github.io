C++20 OpenGL 4.5 GLFW/GLAD GLM Assimp Dear ImGui Premake5 Conan
Details
  • Developing a modular C++20 graphics engine on OpenGL 4.5 core profile, built as a static library consumed by incremental sample applications.

  • Established a reproducible build pipeline: Conan-managed dependencies feeding Premake5-generated Visual Studio solutions, with scripted dependency generation and post-build asset deployment.

About

I'm a Game Programming graduate from ESAT Valencia, currently completing a BSc (Hons) Computer Science for Games top-up year at Sheffield Hallam University. My work sits at the intersection of gameplay engineering and graphics programming — I care about systems that are both correct under the hood and expressive for the people using them.

I've shipped a full production game in Unreal Engine 5 with a team of twenty, and spent the rest of my time writing custom rendering engines, exploring low-level optimisation in ARM64 Assembly, and building the foundations of a C++20 skeletal animation system.

Outside of code I'm interested in how games use rendering to create atmosphere, and in the performance engineering that makes it possible in real time.
